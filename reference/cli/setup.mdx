## Summary

```bash
ralphy setup [options]
ralphy --root /absolute/path/to/library setup --non-interactive
```

Initializes a local SQLite Workspace without a source checkout. Retain the returned `data_root` and `workspace_id`. `--status` is read-only. Credentials are configured separately with scoped `provider auth set <provider> --stdin`.

## Flags

| Flag | Description |
|---|---|
| `--status` | Print capability status as JSON and exit (no TUI) |
| `--link <path>` | Link ralphy to a source checkout (compatibility option) |
| `--unlink` | Remove the global project link |
| `--non-interactive` | Agent / CI mode: never prompt, never open a TUI, emit a JSON summary (default: false) |
| `-y, --yes` | Alias for --non-interactive (default: false) |
| `--openrouter-key <key>` | Deprecated and refused; use provider auth set openrouter --stdin |
| `--elevenlabs-key <key>` | Deprecated and refused; use provider auth set elevenlabs --stdin |
| `--keys-from-env` | Deprecated and refused; project/inherited env is not a credential source (default: false) |
| `--project-dir <path>` | Link ralphy to a source checkout and initialize its Workspace. Implies --non-interactive |
| `--no-verify` | Compatibility flag; setup does not verify credentials |
| `--allow-unverified` | Compatibility flag; setup does not accept or verify credentials (default: false) |
